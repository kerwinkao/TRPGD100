# play/ — 模型 DM 相關

跑團層的東西。解算層在 design/,模擬在 sim/,這裡是桌子。

## 檔案(規劃)
```
play/chargen.md        引導創角流程
play/npc/templates.json NPC 模板(與 sim/ 共用)
play/dm-prompt.md       模型 DM 系統提示詞
play/sessions/          每場的 state 與紀錄
```

## 引導創角
- 模型 DM 的第一場,一對一、對話式、不推演戰鬥。
- 擲幾個骰定方向(家世、背景、奇遇),對話把它長出來:「你家是鏢局,三年前垮了,為什麼?」玩家的回答就是設定。
- 產物:角色卡 + 一頁背景,背景裡埋鉤子給之後的團。
- 起手包依背景給(借款,前三場可挪)。
- 難度階依來歷:散修 1;有師承的本門技能可從 2 起。

## 間隔期單人戲
- 團與團之間玩家可單獨跟 DM 聊:練功、鑽研(幅度累計)、找師門、打聽消息、做生意。
- 真人 DM 沒空陪的部分,模型陪。這是 API 額度的主要用途。
- 產物寫回角色卡與 state;正團開始時 DM 讀。

## NPC 模板
- 全隨機不合理。NPC 有來歷:鏢師、宗門弟子、山賊、郎中。
- 模板 = 原型 + 可變槽:
  ```
  鏢師:屬性偏 Str/Con;刀法 2–4(難度 1)、招架 2–3、反擊 1;刀 + 小盾
  宗門弟子:本門劍法難度 2、2–3 級、專屬副技能一個;步法 2
  山賊:雜,全難度 1,1–2 級;人多
  ```
- **與 sim/ 共用**:模擬的配置原型就是這些模板,不是均值人。模擬數據才對應桌上會遇到的對手。
- 跑團中生出的 NPC 回填模板庫。
