# 裝備基礎估算板(佔位,待細修)

全部數字為推估,供模擬掃描與開團用;KK 審後定稿。

## 重量(kg,中值)
| 類 | 項目 | kg |
|---|---|---|
| 單手武器 | 短刀 0.5 / 長劍 1.2 / 單刀 1.0 / 長槍 2.0 | |
| 雙手武器 | 長棍 1.5 / 大刀 2.5 / 雙手劍 2.5 | |
| 盾 | 小盾 2 / 大盾 5 | |
| 甲 | 布 2 / 皮 6 / 鎖子 12 / 板 20 | |
| 其他 | 隨身行囊 3 / 旅行背包 10 | |

## 負重上限
- 上限 = Con + Con 效益值 × 5。均值(Con 14)24 kg;Con 10 → 10;Con 20 → 45。
- 標定:現實輕裝行軍約 15 kg、全副武裝 25–30 kg 明顯影響動作。
- 盾不直接減閃避,只佔重量。

## 超重減值(按比例,不算公斤)
| 超限 | 效果 |
|---|---|
| ≤ 25% | 閃避、步法 −10 |
| ≤ 50% | 閃避、步法 −20;體力每回合回復 −1 |
| > 50% | 不可閃避、步法;只剩招架、格擋 |

## 護甲吸收(傷勢三位制)
| 甲 | 輕傷位吸收 | 重傷位吸收 | kg | 均值角色可扛? |
|---|---|---|---|---|
| 布 | 1 | 0 | 2 | 可 |
| 皮 | 2 | 1 | 6 | 可 |
| 鎖子 | 3 | 2 | 12 | 可(接近上限) |
| 板 | 5 | 3 | 20 | 需 Con ≥ 16 |

- 護甲是固定吸收,在招架/格擋之後、傷勢結算前扣。
- 對 1d6+2:板甲吃掉過半輕傷、重傷位幾乎不動——「打不死但打得倒」。

## 範例負重
- 散修戰士:長劍 1.2 + 皮甲 6 + 小盾 2 + 行囊 3 = 12.2(均值上限 24,自由)
- 換鎖子甲:18.2(仍可)
- 換板甲:26.2(超限 9%,閃避 −10)
