# 屬性、池、家

## 七屬性(4d6,均值 14,範圍 4–24)

| 代碼 | 名稱 | 管轄 |
|---|---|---|
| Str | 力量 | 輸出力量、負重、傷害加成 |
| Con | 體質 | 身體基本數值、耐久、抗性;體力池、負重上限、Con 系盾手的吸收值 |
| Ski | 靈巧 | 手、上半身——武器操作、格擋、精細動作 |
| Agi | 敏捷 | 腳、下半身——移動、閃避、平衡 |
| Int | 智力 | 腦力——知道、記得、算得出;內源魔法的來源 |
| Wis | 智識 | 理解力——看懂、判斷、舉一反三;外源魔法的來源 |
| Cha | 氣質 | 氣場——玄學力的容量/通道;相貌只是其外顯之一 |

### Int / Wis 裁判口訣(給模型分配技能屬性用)
- Int = 知道、記得、算得出 → 內源(力從自己的運算與意志出)
- Wis = 看懂、判斷、舉一反三 → 外源(力從讀懂世界、借用世界來)

### 屬性效益值(通則)
- 任何「屬性加值」= ⌊(屬性 − 10) / 2⌋,下限 0。14 → +2,20 → +5。
- 無低屬性罰則(與玩家討論後廢除;屬性之後可加強)。
- 盾值常數項、傷害補正、體力回復、負重等一律引用此式,不另寫。

### 不是屬性的東西
反應、感知、儀容、運氣。皆為技能。反應依組合有多種:
- 戰鬥反應 Agi+Ski+Wis
- 臨場反應 Wis+Int+Cha
- 危機反應 Con+Agi+Wis

## 生命值與傷勢(基礎模式)
- 不分部位(部位留給模組)。
- 寫成 **輕傷位 / 重傷位 / 上限**,例 30/30/30。
- 受傷 D:輕傷位 −D,重傷位 −⌊D/2⌋。一刀 12 → 18/24/30。
- 輕傷位休息即回;重傷位需治療。
- 輕傷位 0 → 失能;重傷位 0 → 死亡。
- **單挑時輕傷位打空即勝**,模擬中失能等同擊殺。
- 戰鬥中回復輕傷的手段(藥水、治療術、內力療傷、技能)待補;有這類能力者在此規則下會很強(類 D&D 牧師),是預期。
- 護具分輕重傷位各自吸收。
- 上限公式依家:標準 **Str+Con**;可選 Con+Con;修行人 Con+Wis。Str+Str 禁(太怪)。均值角色 28。

## 能源池

### 天生池(屬性加總,人人有)
| 池 | 通行名 | 公式 | 用途 |
|---|---|---|---|
| 精 | 體力 | Con+Con | 疊攻、疊防禦層、一般體能超量。每回合回復 Con 效益值(⌊(Con−10)/2⌋);回氣類技能可增 |
| 內源魔力 | — | 依家:Int+Int 或 Int+Wis | 內源術 |
| 神 | 神識 | 依家:Wis+Wis 或 Wis+Cha | interrupt、感知/反應類超量、外源術通道費 |

### 練成池(技能,從 0 起)
| 池 | 通行名 | 底 | 說明 |
|---|---|---|---|
| 氣 | 內力 | Con+Cha+Wis | 體力線的下一階。內功技能等級 ≥ 1 才有;池量 = Con、Cha、Wis 效益值之和 × 內功難度階序號 × 內功等級。均值散修一級 6。**內功等級上限 = 三效益值中最小者**(全 +2 → 二級、全 +3 → 三級、任一為 0 → 修不出)。門派內功另議。用途見 resolution「內力」 |

內功難度階的世界觀刻度:1 散修、2 名門正派內門、3 嫡傳、4 以上修真。同為二級、效益值全 +2:散修 12、內門 24、嫡傳 36。

高手「打一整天」的主因不是內力池,是技能等級給的低價次數(見 resolution 消耗格)。內力池是第二個錢包。

心線、靈線是否也有練成階:**待定**。

### 三線對照(機械名;label 見 systems.md 的 school 表)
| 線 | 一階(天生) | 二階(練成) | 三階(高位) |
|---|---|---|---|
| 精(身) | 精1 體力 Con+Con | 精2 內功技能 | 精3 |
| 氣(心) | 氣1 依 school | 氣2 主術技能 | 氣3 |
| 神(靈) | 神1 依 school | 神2 神識修練 | 神3 |

單點強度每階 ×5。內源 Int / 外源 Wis 是「源」,是池的屬性不是線的屬性:同一條氣線容納 Int 主與 Wis 主兩種 school。完整規則見 systems.md §1。

### 換池
- 換池是副技能(型別:定向超量,目標為池),佔副技能槽,每級上限 10 點。
- 無另設折損;槽位與經驗的機會成本即煞車。
- 純 Int 家(Int+Int)開 Wis 轉 Int 是浪費主線;賢者家(Int+Wis)天生兩池。見仁見智,交給配置矩陣。

## 家(school)
- 池公式掛在家上,不掛在角色上。角色選家即定池。
- `school.pools` 欄位決定內源魔力與神識的公式;`school.hp` 決定生命上限公式(Str+Con / Con+Con / Con+Wis)。
- 前面「神識有的 Wis+Wis、有的 Wis+Cha」即此:家不同,非規則模糊。

## 三屬性校準範例
| 技能 | 三屬性 |
|---|---|
| 長劍 | Str+Ski+Agi |
| 閃避 | Agi+Con+Wis |
| 招架 | Ski+Str+Wis |
| 格擋(盾) | Ski+Con+Str |
| 戰鬥反應 | Agi+Ski+Wis |
| 察覺 | Wis+Int+Cha |
| 內功 | Con+Cha+Wis |
| 內源術 | Int+Con+Cha |
| 外源術 | Wis+Cha+Con |
| 化妝 | Ski+Cha+Wis |

Con 在兩種術裡都出現,因為付代價的是身體。
