# 戰鬥系統:近戰與法術(古典)

近現代(槍械、CPB、軍事)**未設計**,待高武高法成熟後再加——槍的問題不是傷害,是沒有防禦層;等「以氣禦劍」「法盾」存在,槍才有東西可對抗。

原則:三系統不是三棵樹,是同一個解算器上不同的「池 × 防禦層 × 傷害入口」。判定、幅度、致命、主動權交換全部共用。

## 1. 池:線 × 階 × 源

### 機械名(解算器、模擬、角色卡結算只認這個)
```
線:精(身)/ 氣(心)/ 神(靈)
階:1 天生 / 2 練成 / 3 高位 / 4 修真(留白)
源:Int 主 / Wis 主 / 混(標主輔);精線無源
池 ID = {線}{階}:{源}    例 氣2:Int+Wis、精2、神2:Wis+Cha
```

### 階的換算(單點強度)
- 二階一點 = 一階五點;三階一點 = 二階五點 = 一階二十五點。
- 低階術可用高階池付,照換算(金丹丟築基術付 1/5 點——「隨手」)。
- **高階術不能用低階池湊**:術標 `min_tier`,池階不足不可發。這是質變的門檻。
- 模擬以「一階當量」統一比較:散修體力 28 = 28 當量;築基 12 真元 = 60;普通金丹 10 丹元 = 250。
- 解算器唯一改動:池為 `{線, 階, 值}`,付費 `cost / 5^(池階 − 術階)`。

### 一階池(天生,屬性加總)
| 線 | 預設公式 | 用途 |
|---|---|---|
| 精1 | Con+Con | 體力:疊攻疊防、體能超量;每回合回 Con 效益值 |
| 氣1 | 依 school(Int+Int / Int+Wis / Wis+Wis / …) | 施術 |
| 神1 | 依 school(Wis+Wis / Wis+Cha / …) | interrupt、預判、反制、外源通道費 |

### 二階池(練成,技能)
- 公式:三屬性效益值和 × 技能難度階 × 等級;等級上限 = 三效益值最小者(見 attributes 內功)。
- 精2 = 內功技能;氣2 = 該 school 的主術技能;神2 = 神識修練技能。

### 回復與轉換:是功法,school 給門路
- 回復率、階間轉換由**功法**(技能)提供,花經驗練。
- 功法有前置:靈根(五行)、屬性、replace 規則。不滿足練不上去。
- school 提供的是門路:師承告知哪本合你、該用哪個屬性、怎麼 replace;散修隨機撿,練不上去也不知道為什麼。**前置是否被告知屬 roleplay,進 DM 提示詞,不進規則。**
- 親傳弟子「大池、高回復、可轉換」是因為有人指路;雜魚金丹只有幾點丹元不回,是撿錯了功法。
- 這是中期戰力分歧的主因,見 principles §10。模擬掃三階回復 {0, 1, 2}/回合,看「發完大招就慘」與「活蹦亂跳」的分界。

### 三階池(高位)
- 另一門技能,從 0 練;前置:對應二階技能達某級且難度 ≥ 3(與「基礎劍法→華山劍法」同構)。數值待定。

### school 對照表(label 是皮,機械名是真相)
每個 school 一張表,欄位:
```
pool_id      機械名
label        該世界觀的名字(可與別的 school 撞)
formula      一階公式 / 二階倍率覆寫
replace      屬性替換(如「氣2 以 Cha 代 Wis」);早年「Cha 混進來」的狀況全進此欄
multiplier   一階池放大(練氣 = 氣1 × 2 之類)
```
範例:
| school | 氣1 | 氣2 | 氣3 |
|---|---|---|---|
| 西幻法師(Int 主) | 魔力 | 法力 | 奧術本源 |
| 紫府金丹修士(Wis 主) | 練氣(×2) | 築基 / 真元 | 金丹 / 丹元 |
| 散修武者 | — | 精2 內力 | 精3 內勁 |
| 神官(Wis+Cha) | 信力 | 神恩 | 神諭 |

模型 DM 對玩家講 label,結算用機械名。divine、仙俠、符籙、西幻全是 school,不另立規則。

## 2. 八系(D&D 3e 分類,當 family 用)

| 系 | 攻擊方式 | 守方可用層 | 燒 | 特誤反噬打 |
|---|---|---|---|---|
| 塑能 | 對抗:幅度 vs 閃避 / 反制 / 抗性 | 閃避、反制、抗性 | 氣 | 氣池上限 |
| 附魔 | 對抗 vs 意志 | 抗性、反制 | 神 | 神池上限 |
| 幻術 | 對抗 vs 察覺 / 意志 | 察覺、反制 | 神 | — |
| 死靈 | 對抗 vs 體質 | 抗性 | 氣 + 生命 | 生命上限 |
| 防護 | 不對抗:給自己 / 隊友防禦層 | — | 氣 | 氣池上限 |
| 變化 | 自身不對抗 / 對敵對抗 vs 抗性 | 抗性 | 氣 | 生命上限 |
| 咒法 | 不對抗:召喚物走近戰規則 | — | 氣(持續) | 召喚物反噬 |
| 預言 | 不對抗:給資訊(預判的放大) | — | 神 | — |

- 只有塑能、附魔、幻術、死靈走防禦鏈;其餘是改角色卡 / 場景的動作。
- 內源 / 外源與八系是兩個軸。**傾向(讀法 B)**:塑能、變化、死靈偏 Int;咒法、預言、防護偏 Wis;附魔、幻術兩可。school 練偏向不合的系,難度階 +1(佔位,待裁)。
- 預言系與預判同構:預判難度定了,預言跟著它。
- 五行 / 八卦 / 三才是**標籤**,不是樹:每個術帶 `wuxing`、`bagua` 欄。五行生剋進對抗修正:生 +10 / 剋 −10,雙向,**基礎有影響但不絕對**。八卦進場景(陣法方位),不進判定。

## 3. 法術的防禦層

- **反制**:法術的招架。腦格一動,擲對應術系,成功侵蝕攻方幅度;成功即換手。沒它法師互打是純攻擊競賽。
- **抗性**:非法師對法術的層(意志類技能,Wis+Con+Cha 佔位)。成功只減傷,**不換手**——抗過不等於能反手打法師。
- **反噬**:術特誤(00)打自己對應池的上限(接「內傷降池上限」)。

## 4. 法師的三層殼

戰鬥中的法師通常都有:
| 層 | 來源 | 機制位置 | 換手? |
|---|---|---|---|
| 護盾(短期) | 防護系術 | 個人防禦層,固定吸收 N 點、吃完消失(走格擋的位置) | 否 |
| 結界 / 法陣(長期) | 防護 / 咒法 | 場景層,範圍內所有人吃修正(含五行);「大夥一團混」 | — |
| 瞬發掛載 | 任一系 | 預付、宣告觸發條件;觸發時不佔格不擲(已擲)。法師的 interrupt,對應反擊 | 依術 |

- 掛載數上限:神2 等級(佔位)。
- 刀客對法師的戰鬥形狀:破盾(固定吸收)→ 陣裡打(修正)→ 提防掛載(觸發)。三道都是數線加減。

## 5. 距離(最小規則,一頁)

| 檔 | 近戰 | 法術 |
|---|---|---|
| 近身 | 全部防禦層可用 | 可施,反制可用,施術者可被招架打斷(佔位) |
| 中距 | 不可攻擊;移動一動(腳格)進近身 | 可施;守方閃避、反制、抗性 |
| 遠距 | 不可 | 範圍術、預言;守方只有抗性 |

- 法師對刀客的全部張力 = 近身前後。沒距離則張力不存在。
- 移動佔腳格、付累進;步法可縮短(佔位)。
