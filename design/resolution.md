# 判定機制

## 基本擲骰
- d100,擲越小越好(roll-under)。
- 技能值 = 三屬性加總 + 10 × 等級 + 疊加。
- 成功:擲值 ≤ 技能值。幅度 = 技能值 − 擲值。
- 範例:52 擲 17 → 成功,幅度 35。

## 致命與特誤(隨比率縮放)
- 致命區 = 成功範圍的頂端 10%(擲值最低的那段)。技能 52 → 01–05;技能 125 → 01–12。
- 特誤區 = 失敗範圍的底端 10%。技能 52 → 96–99。
- **00 固定為特誤,不隨技能消失**。這是骰子的調味料;中高階靠重骰類副技能消除。
- 重骰只能消 00,不能消一般失敗。

## 溢出(技能值 > 100)
- 每一擲都成功,幅度 = 技能值 − 擲值。
- 固定溢傷:超出 100 的部分直接成為傷害加成(125 → +25% 傷害)。
- 致命區隨之擴大(125 → 01–12)。**疊破百的真正獎勵是致命率從 1% 變 12%**,溢傷是其次。
- 溢出狀態下擲出致命:武器傷害骰直接滿骰。
- 系統設計意圖:中高階玩家本來就該疊到破百。

## 疊加
- 技能可疊,需 roleplay 上的合理說明,DM 與玩家共同裁定。
- 常態疊法進白名單(由技能表 `canonical_stacks` 維護),白名單內不必每次確認。
- 模型 DM 只准白名單;白名單外一律視為需玩家明示理由,且 DM 得拒絕。
- 疊攻、疊防禦層燒體力(或內力,視技能宣告的池)。代價尺度待模擬定。

## 對抗:幅度侵蝕鏈

攻方先擲,得幅度 T。守方逐層防禦,每層消耗 T:

```
T = 攻擊幅度
for 每一層防禦 (skill%, level):
    r = d100
    if r == 00:
        特誤 → 後果待定(open-questions)
    elif r > skill%:
        失敗 → T 不變,下一層
    else:
        m = skill% − r
        if m ≥ T:
            完全防禦,結束
        else:
            T −= min(m, 10 × level)
T > 0 → 進傷判
```

- 侵蝕上限 = 10 × 該層技能等級。三級閃避最多吃 30;擲出來幅度只有 3,就只吃 3。
- 等級是天花板,不是保證。% 管「發不發生」,等級管「發生了多大」。
- 守方致命(擲極低)自然等於吃滿上限,不另設規則。
- 守方宣告時機:**待定**(先宣告整鏈 vs 看到剩餘 T 逐層決定)。

### 可用防禦層依攻擊類型
| 攻擊 | 可用層 |
|---|---|
| 近戰 | 閃避 → 格擋 → 盾擋 |
| 投射 | 閃避(限宣告前已移動)→ 掩體 → 護甲 |
| 槍械 | 掩體 → 護甲(無閃避層) |

槍的傷害照實,但沒有技能能侵蝕它;守方槓桿從身手換成位置與裝備。解算器同一函數,只換層清單。

## 難度判定(DM 直接丟難度)
- 同一機制:難度 D 即 T。
- 相關知識/技術判定成功,侵蝕 D,上限 10 × 等級。
- 範例:陷阱解除難度 75(不告知),陷阱種類判定二級通過,最多削 20 → 55。

## 傷判
- 武器傷害骰(長劍 1d8;多骰版本用 d4–d20 各式)。
- 溢傷加成、致命滿骰如上。
- 外傷 → 生命上限下降。內傷 → 能源池上限下降(待確認)。
- 傷判細則:**待定**。

## interrupt
- 系統有大量 interrupt。窗口由反應類技能決定;超量行為付代價(神識為主)。
- 代價尺度:**待定**。

## 文戲
- 嘴砲靠玩家的嘴,不靠骰。
- DM 提示詞一條:以對話內容裁決;僅在後果涉及身體或資源時擲一次。

## 使用紀錄(用則長的基礎)
每次擲骰記一行:
```
session, turn, actor, skill, roll, skill%, margin, challenge_value, consequence(bool), xp_pool
```
- 場末 `groupby(skill)` 即各技能經驗。
- 只計 `consequence = true` 的使用。對空氣招架不給。
- 連續 N 場零紀錄的技能 → 標記給 DM,提示下一場塞一個需要它的局。
