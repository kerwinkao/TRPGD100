# 判定機制

## 基本擲骰
- d100,擲越小越好(roll-under)。
- 技能值 = 三屬性加總 + 10 × 等級 + 疊加。
- 成功:擲值 ≤ 技能值。幅度 = 技能值 − 擲值。
- 範例:52 擲 17 → 成功,幅度 35。

## 致命與特誤(隨比率縮放)
- 致命區 = ceil(技能值 × 10%) + 致命類副技能加值。**不封頂,無條件進位**。技能 52 → 01–06;技能 9 → 01;技能 125 → 01–13;150 + 致命副技能三級 → 01–18。
- 致命區是設計上要疊的東西:技能值與致命副技能是兩條獨立加法線。
- 致命必須先是成功(致命區疊得比技能值大時,超出部分無效)。
- 特誤區 = 失敗範圍的底端 10%,同樣無條件進位。技能 52 → 失敗範圍 48,ceil(4.8)=5 → 96–00。技能 ≥ 100 時只剩 00。
- **00 固定為特誤,不隨技能消失**,溢出狀態亦然:00 永遠是特誤,不是成功。中高階靠重骰類副技能消除。
- 重骰只能消 00,不能消一般失敗。
- 攻方特誤 = 失手;防禦層特誤 = 該層失效、T 不變、鏈繼續。更重的後果(整鏈崩、開反擊窗)留給副技能。

## 溢出(技能值 > 100)
- 每一擲都成功(00 除外),幅度 = 技能值 − 擲值。
- 溢傷:超出 100 的部分成為傷害加成,**單位是點**(125 → 傷害 +25 點)。
- 致命區隨之擴大(125 → 01–13)。**疊破百的真正獎勵是致命率從 1% 變 13%**,溢傷是其次。
- 溢出狀態下擲出致命:武器傷害骰直接滿骰。技能剛好 100 不算溢出。
- 系統設計意圖:中高階玩家本來就該疊到破百。

## 疊加
- 技能可疊,需 roleplay 上的合理說明,DM 與玩家共同裁定。
- **疊加加的是被疊技能的全值**(底值 + 10 × 等級)。52 疊 52 = 104。
- 常態疊法進白名單(由技能表 `canonical_stacks` 維護),白名單內不必每次確認。
- 模型 DM 只准白名單;白名單外一律視為需玩家明示理由,且 DM 得拒絕。
- 疊加是一次動作,佔消耗格(見下)。

## 回合與消耗格

- 一回合 6 秒。
- 每個角色有三個**消耗格**,每回合歸零:
  - **手格**:攻擊、招架、格擋、雙持、所有上半身動作
  - **腳格**:閃避、步法、移動
  - **腦格**:算力、施法、ESP
- 同格內第 k 次動作耗 k 點體力(或該技能宣告的池),**不分技能**:長劍攻、盾擋、再長劍攻 = 1、2、3。
- 技能等級給**低價次數**:該武器/技能本回合前 `ceil(level/2)` 次動作各耗 1 點(等級 1/3/5/7/9 → 1/2/3/4/5 次)。用完才進入該格的累進。
- 高手超出低價次數照樣動,自己算一動值不值 3 點。回氣類能力讓這筆帳划算。
- 6 秒內燒光體力是合法的,只是不正常。
- 攻擊系副技能可攻擊對手的格:「強彈劍」類效果 = 目標某格下一動額外 +N 或本回合低價次數 −1。

### 手的動作可互相宣告
- 一把武器的低價次數,攻守由玩家當場分配:副手短劍第一次攻擊可宣告為招架,吃短劍的次數。
- 主手第一次攻擊宣告成招架也合法——沒反傷就是龜。

### 雙持
- 無雙持技能硬雙持:主手攻擊 −10,副手攻擊 −30;格擋不減。
- 雙持一級:兩手各 −10。等級高先抵銷副手減值。
- 初期副手限短兵;雙長劍為高階 `action` 型副技能。

## 對抗:防禦鏈

攻方擲武器技能,得幅度 T。守方逐層防禦。**閃避類侵蝕 T;招架與格擋不碰 T,改做傷害對抗。**

```
T = 攻擊幅度
—— 腳格:步法 / 閃避 ——
步法(Step):擲;成功 → 幅度 S 轉為下一動的技能值加值(進技能值,不進侵蝕上限)
閃避(Dodge):技能值(+S);擲
    r == 00          → 特誤,該層失效
    r > skill        → 失敗,T 不變
    m = skill − r
    m ≥ T            → 全閃,結束          (用原始 m,不受等級上限)
    否則             → T −= min(m, 10 × level)
—— 手格:招架 / 格擋 ——(T > 0 才進來)
招架(Parry):擲招架技能;成功 → 守方擲武器傷害骰 D_def
格擋(Block):擲格擋技能 + 10(裝備加成);成功 → D_def = 盾值(固定)
—— 傷判 ——
D_atk = 武器骰 + 溢傷 (+ 致命滿骰)
傷害 = max(0, D_atk − D_def)
T 不進傷判;T 只管閃不閃得掉。
```

- 閃避:侵蝕上限 = 10 × 等級;擲出來幅度只有 3 就只吃 3。等級是天花板不是保證。**全閃用原始 m**——疊步法把閃避疊破百就是在賭全閃,賭輸 T 幾乎原樣進來,體力也花了。
- 步法與閃避同屬 Agi、同吃腳格:先步法再閃避 = 1 + 2 = 3 點。
- 招架:吸收隨機(武器骰),長劍 1d8、短刀 1d4。無副技能不反傷;反超需副技能。
- 格擋:吸收固定。盾值:小盾 1 + ⌊(Str−10)/2⌋,大盾 2 + ⌊(Str−10)/2⌋,下限 0。
  - Con 系盾手可用 Con 代 Str 算盾值,但**阻斷**(格擋打斷對方動作)為 Str 系副技能專屬。格擋技能下天然兩條線:吸收線(Con 可)、阻斷線(Str 限)。
- 卸力(小盾/護臂):固定吸收,可疊在閃避之後、傷判之前。
- 守方逐層決定、只付擲了的層。

### 負重
- 裝備(盾、甲、武器)各有重量,總和超過 Con 決定的負重上限才減閃避。**盾不直接減閃避**。
- 佔位公式:負重上限 = Con × k;超出每 1 單位閃避 −2。k 待定。
- Con 的三個用途:體力池、吸收值(Con 系盾手)、負重。

### 可用防禦層依攻擊類型
| 攻擊 | 可用層 |
|---|---|
| 近戰 | 步法/閃避 → 招架 → 格擋 → 卸力 |
| 投射 | 閃避(限宣告前已移動)→ 掩體 → 護甲 |
| 槍械 | 掩體 → 護甲(無閃避層) |

槍的傷害照實,沒有技能能侵蝕它;守方槓桿從身手換成位置與裝備。解算器同一函數,只換層清單。

## 難度判定(DM 直接丟難度)
- 難度 D 即 T,只有侵蝕層。
- 相關知識/技術判定成功,侵蝕 D,上限 10 × 等級。
- 範例:陷阱解除難度 75(不告知),陷阱種類判定二級通過,最多削 20 → 55。
- 削完之後:主判定(解除技能)擲,幅度 ≥ 剩餘 D 即成功。

## 傷判
- 武器傷害骰(長劍 1d8、短刀 1d4;多骰版本用 d4–d20 各式)。
- 溢傷(點)、致命滿骰如上。
- 外傷 → 生命上限下降。內傷 → 能源池上限下降(待確認)。
- 生命值公式:**待定**。

## interrupt
- 系統有大量 interrupt。窗口由反應類技能決定;超量行為付代價(神識為主,吃腦格)。
- 代價尺度:**待定**。

## 文戲
- 嘴砲靠玩家的嘴,不靠骰。
- DM 提示詞一條:以對話內容裁決;僅在後果涉及身體或資源時擲一次。

## 使用紀錄(用則長的基礎)
每次擲骰記一行:
```
session, turn, actor, skill, roll, skill%, margin, challenge_value, consequence(bool), xp_pool
```
- 場末 `groupby(skill)` 即各技能經驗。
- 只計 `consequence = true` 的使用。對空氣招架不給。
- 連續 N 場零紀錄的技能 → 標記給 DM,提示下一場塞一個需要它的局。
